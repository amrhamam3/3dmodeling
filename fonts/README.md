# مجلد الخطوط

ضع هنا أي خط TTF يدعم رموز اللغة العربية، وسمِّه بالضبط:

```
NotoSansArabic-Regular.ttf
```

## من وين أجيبه؟
حمّل خط "Noto Sans Arabic" مجاناً من Google Fonts:
https://fonts.google.com/noto/specimen/Noto+Sans+Arabic

(اضغط "Download family"، فك الضغط، انسخ أي ملف .ttf ثابت (Static) منه هنا وأعد تسميته
`NotoSansArabic-Regular.ttf`. تجنّب الخط المتغيّر Variable Font لو واجهت مشاكل عرض.)

بدائل تعمل بنفس الطريقة: خط Amiri (https://github.com/aliftype/amiri) أو أي خط TTF آخر يدعم Unicode Arabic (U+0600–U+06FF).

## لو الملف غير موجود
البرنامج ما يتعطل - فقط يستخدم الخط الافتراضي (لاتيني فقط) وتظهر الحروف
العربية كعلامات استفهام، مع رسالة تنبيه بالـ Console توضح المشكلة.

## قيد معروف: الحروف تظهر منفصلة
حتى بعد إضافة الخط، Dear ImGui لا يملك محرك تشكيل نصوص عربي (لا HarfBuzz
ولا FriBidi)، فالحروف تُرسم منفصلة عن بعضها (بدون الاتصال الطبيعي للخط
العربي) ومن اليسار لليمين. هذا قيد بالمكتبة نفسها. الحل الكامل يحتاج دمج
مكتبتي تشكيل نص منفصلتين قبل تمرير أي نص عربي لـ ImGui::Text.
